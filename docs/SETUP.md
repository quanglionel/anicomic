# Setup Tu So 0

## Muc tieu buoc 1
- Co monorepo khung cho `apps/web` va `apps/api`.
- Chua can chay app, chi chot cau truc va script.

## Khi bat dau code thuc te
1. Cai Node LTS tren moi truong dev (local hoac remote).
2. Bat Corepack: `corepack enable`.
3. Cai dependency: `pnpm install`.
4. Chay web: `pnpm dev:web`.
5. Chay api: `pnpm dev:api`.

## Khuyen nghi local gon
- Dung VS Code Remote/Codespaces de tranh cai dat nhieu tren may chinh.
